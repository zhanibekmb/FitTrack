# FitTrack

Your workouts. Your progress.

FitTrack is an Android gym workout journal.

## Features
- Workout planning
- Workout tracking
- Rest timer
- Workout history
- Progress statistics

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM
- StateFlow
- Navigation Compose
